# Contributing to LuAI Tools · AI Tools Directory

Thanks for helping grow this list! Submissions are free and welcome. Please read the short rules below before submitting — following them makes review fast and painless.

## Ways to contribute

- **Submit a new tool** — via issue (easiest) or pull request.
- **Fix a broken link or outdated description** — pull request welcome.
- **Suggest a new category** — open an issue first so we can discuss it.

## Acceptance criteria

A tool will be added if it:

- Is publicly accessible (has a working website) and functional.
- Is related to AI (tool, product, or directory).
- Is not already in the list.

## Formatting rules

1. **Alphabetical order** — sort entries by tool name within each category.
2. **Table format** — use the exact structure already in `README.md`:

   ```markdown
   | [Tool Name](https://example.com) | One-line factual description (max 80 chars) | [Website](https://example.com) |
   ```

3. **One line per tool**, no extra columns.
4. **No superlatives** — write what it does, not "the best" / "amazing" / "#1".
5. **No affiliate or referral links** — plain product URLs only.
6. **One tool per submission.**

## Pull request checklist

Before opening a PR, confirm:

- [ ] Added to the correct category.
- [ ] Inserted in alphabetical order.
- [ ] Followed the existing table format exactly.
- [ ] Description is factual and under 80 characters.
- [ ] No referral/affiliate links.
- [ ] Not a duplicate of an existing entry.

## Review process

- A maintainer reviews submissions, usually within a few days.
- If something needs a change, we'll leave a comment — please reply rather than opening a new issue.
- We may decline submissions that don't meet the criteria (commercial-only promotions, dead links, duplicates).

Thank you for contributing! 🙌
