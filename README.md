## 📖 How to submit a tool

There are two ways, pick whichever is easier for you:

**Option A — Open an issue (fastest, no Git needed)**

1. Go to the [Issues](https://github.com/lidalu1988/LuAITools/issues) tab.
2. Click **New issue** → **Submit a tool**.
3. Fill in the name, URL, one-line description, and category.
4. Submit. A maintainer will review and add it, usually within a few days.

**Option B — Send a pull request (standard)**

1. Fork this repository.
2. Edit `README.md` and add your tool to the right category, in **alphabetical order**.
3. Follow the existing table format exactly (see below).
4. Open a pull request with the title `Add <Tool Name>`.

Table format:

```markdown
| [Tool Name](https://example.com) | One-line factual description (max 80 chars) | [Website](https://example.com) |
```

## 📏 Submission rules

- The tool must be publicly accessible and actually work.
- One-line description, factual, **no superlatives** (avoid "best", "amazing", "#1").
- No referral or affiliate links.
- Keep each category sorted alphabetically by tool name.
- One tool per submission. Don't submit duplicates.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full rules.
